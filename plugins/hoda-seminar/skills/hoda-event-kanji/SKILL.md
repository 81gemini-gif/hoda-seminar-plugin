# イベント幹事の手引き

## 幹事の心得

- **幹事は「誰かがやってくれるもの」ではない。**自分たちがスムーズに物事をやれている背景には、そのために準備をしてくれた人がいる（→ `hoda-context` スキルの references/code-of-conduct.md）
- **ATI（圧倒的当事者意識）とラストマンシップ。**最後まで自分が責任を持つ
- **リマインドされたらおしまい。**ゼミ長から催促される状態になった時点で遅れている
- 困ったら**抱え込まずにゼミ長に上げる。**巻き取ってもらう判断も含めて早い方がよい

## 合同ゼミ（最重要）

### 立ち上げ

- [ ] **Slackに幹事チャンネルを作成する。**やり取りを個人DMに閉じない
- [ ] 先方大学のゼミの窓口担当を特定し、連絡経路を確立する
- [ ] ゼミ長をチャンネルに入れる（**ゼミ長は監視する責任がある**）

### 先方との調整項目

- [ ] 開催日時・会場（どちらのキャンパスか、オンライン併用か）
- [ ] **参加ゼミの数と各ゼミの発表枠数**
- [ ] 発表時間と質疑時間
- [ ] 資料の提出先・締切・形式（pptxかpdfか）
- [ ] 当日のタイムテーブル
- [ ] 懇親会の有無・会費・場所
- [ ] 各ゼミの参加者数（**個人情報を含むリストは渡さない。**氏名・学年・学部まで）

### 保田研内の調整

- [ ] **10月末までに「どの班が発表するか」を全体の議論に上げる。**発表班の決定は毎回ギリギリまで決まらないので、能動的に議題化する（ゼミ長と連携）
- [ ] 参加者を募り、出欠を名簿のイベント列に記録する
- [ ] 移動手段・宿泊の手配（大阪開催なら特に。交通費の扱いを会計と詰める）
- [ ] **資料の提出フローを決める。**過去の運用例：各チームがpptxで提出 → 幹事側で全チーム連結のpdf化を行う
- [ ] 提出締切を発表日の**1週間以上前**に設定する（例：11/30開催に対し11/21金締切）
- [ ] **英語話者メンバーへの情報共有。**日本語だけで流さない
- [ ] 共通アウトフィットの有無を確認する（イベント運営部の所管）

### 当日

- [ ] 集合時間・場所の最終アナウンス（前日）
- [ ] 機材確認（HDMI／USB-C、スクリーン比率16:9）
- [ ] 資料のバックアップを幹事が持つ
- [ ] **他大学の発表内容と質疑をメモする担当を決める。**持ち帰る学びがここにある
- [ ] 写真を撮る（広報部に渡す）

### 事後

- [ ] 先方へお礼の連絡
- [ ] 発表資料・議事メモをDriveに保存
- [ ] **引き継ぎメモを書く**（下記）
- [ ] 会計精算

## ゼミ合宿

- [ ] 日程・場所・予算を決める（会計と連携）
- [ ] **新規生の参加可否を確認する**（新規生参加必須の扱いになることがある）
- [ ] 出欠を名簿のイベント列で管理する（`8/3合宿` のように列を追加する運用）
- [ ] コンテンツを決める（先生の課題読書、PJ顔合わせ、実証分析のワークなど）
- [ ] 移動・宿泊・食事の手配
- [ ] **5限休講の可能性など、通常のゼミへの影響をゼミ長・授業運営部と共有する**
- [ ] しおり・アナウンスを英語話者にも届く形で作る

---

## 工場見学・企業訪問

- [ ] 先方の受け入れ担当と日程調整（3ヶ月前から動く）
- [ ] 参加者リスト（**学籍番号・メールアドレスは入れない**）
- [ ] 移動手段と集合時間。遠方の場合は前泊の要否
- [ ] 服装の指定、持ち物、撮影可否、機密保持の扱い
- [ ] 事前学習（訪問先の有報・統合報告書を読む。質問を用意する）
- [ ] **訪問後は感謝のメールを作成して送る**

---

## 講演会

- [ ] 登壇者との日程・テーマ調整
- [ ] 謝礼・交通費の扱い（会計・先生と確認）
- [ ] 会場・機材
- [ ] 事前の告知と参加者募集
- [ ] 参加者に事前予習の案内（登壇者の著書・経歴・関連記事）
- [ ] 当日の司会進行、質疑の仕切り
- [ ] **お礼のメール**

---

## 引き継ぎメモ（幹事が最後にやること）

**保田研は毎学期人が入れ替わる。書かないと来年ゼロから始まる。**Driveに置いてSlackでピン留めする。

必ず書くもの：

- [ ] **先方の窓口担当と連絡先**（メール、Slack、担当者の所属）
- [ ] **実際のスケジュール**（いつ何をやったか）と、**それが早かったか遅かったか**の所感
- [ ] 予算の実績（項目別）
- [ ] **詰まったところと、その原因**
- [ ] 提出物の形式・締切・提出先
- [ ] 会場・宿・移動の手配先と、良かった／悪かった点
- [ ] **次回やるならこう変える**という提案

**「うまくいったこと」より「詰まったこと」を厚く書く。**次の幹事が助かるのはそちら。

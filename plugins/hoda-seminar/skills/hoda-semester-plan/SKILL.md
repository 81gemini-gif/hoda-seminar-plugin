# 学期スケジュール設計

**学期が始まる前に終わらせる作業。**学期開始時点で「向こう1〜2ヶ月分の輪読スケジュールが決まっている状態」を作るのが目標。

## Step 1：外部固定の日程を先に置く

自分たちで動かせない日から埋める。

- [ ] 学事日程（開講日、最終回、休講日）。**三田祭休講、早慶戦の延長日**などSFC固有の変則日を確認する
- [ ] **合同ゼミの日程**（大阪大・一橋大は11月末〜12月頭、早稲田大は12月中旬が通例）。先方大学との調整が要るので最優先で確定させる
- [ ] **ゼミ合宿**（春は4月、秋は8〜9月）
- [ ] **日経統合報告書アワードの採点期間**（12月下旬〜1月）
- [ ] コンペの締切（日経ストックリーグは1月中旬、他は要項確認）
- [ ] 工場見学・企業訪問（先方都合）
- [ ] OBOG会（8月）、追いコン（学期末）

## Step 2：先生と詰める

**学期前に保田先生と相談して決めること。**

- [ ] **今期は企業PJがあるのか／ないのか**
- [ ] あるなら、**どこの企業と、いつ、どんなスパンで**
- [ ] ないなら、**何でプロジェクトワークを代替するのか**（実証分析、コンペ、懸賞論文）
- [ ] 輪読コンテンツの候補（→ Step 3）に対する先生の意見
- [ ] 中間発表・最終発表の日程

## Step 3：輪読コンテンツを選ぶ

**選定の母体は、ゼミ生が学期末に提出する継続フォーム。**提出要件として「輪読で扱うべきコンテンツ＋その輪読ファシリ資料」が含まれている。**ここから選ぶ。**

1. 継続フォームの提出内容を一覧化する
2. 授業運営部とゼミ長で候補を絞る（HBSケース／実証論文／直近の実事例のバランスを取る）
3. 先生と相談して固める
4. **ファシリ担当を割り当てる**（日本語2名＋英語2名の4名体制。提出者本人が担当するのが基本）
5. **依頼を出して「済」にする。**シートに名前を書いただけでは依頼していない

詳細は `hoda-weekly-ops` を見る。

## Step 4：PJ体制を決める

- [ ] テーマ／提案先企業を確定させる
- [ ] **日本語チームと英語チームに分けて編成する**（名簿の `J or E` 列）
- [ ] チーム名は `チームN（提案先企業名）` 形式。1社に日英2チームが付く形も可
- [ ] 1チーム4〜6名。**在籍学期数と学年を散らす**
- [ ] **リーダーを在籍2学期目以上から立てる**
- [ ] 留学・休学予定者を除外する（名簿の `留学` `休学` セクション）

編成の詳細は `hoda-context` スキルの references/org-structure.md を見る。

## Step 5：週次に落とす

以下の設計で毎週を組む。

| コマ | 基本 |
|---|---|
| **4限** | 輪読・ケーススタディ・研究発表（保田先生がいるコマ） |
| **5限** | PJワーク。**月1回は進捗報告会＋360°FB回** |

### バッファを必ず置く

**イベント前の回はバタつく。**過去の運用でも「合ゼミ前の回は輪読コンテンツを決定せずバッファを確保する」判断が取られている。

バッファを置くべき回：

- 合同ゼミの**前の回**（発表者決め、資料の詰めで潰れる）
- PJ中間・最終発表の**前の回**
- 統合報告書アワードの採点期間中

バッファを置いたら、**シートの `その他` 列に理由を書き残す。**次学期の運営者に効く。

### 逆算の締切を週次に書き込む

| イベント | シートに書き込む締切 |
|---|---|
| 合同ゼミ | D-30：発表班確定 ／ D-9前後：**事務局への資料提出**（過去例：11/30開催に対し11/21金までにpptx提出） ／ D-7：リハ |
| PJ中間・最終発表 | D-14：スライド初稿 ／ D-7：リハ ／ **翌週：360°FB** |
| コンペ | D-90：班確定 ／ 締切日時（時刻まで） |
| 統合報告書アワード | 説明回 → 採点期間 → 共有回 の3点をシートに置く |

### 提出物の形式も先に決める

過去に論点になった例：

> 大阪発表チームは11/19中にスライド資料をpptxで提出する。各チームごと＋全チーム連結のpdf化はこちらでやった方が便宜上良い

**誰がpptxを出し、誰がpdfに束ねるか**を学期頭に決めておく。

## Step 6：シートを初期化して共有する

週次スケジュールシートの全行を作り、埋まる範囲を埋める。列構成は `hoda-weekly-ops` を参照。

- [ ] 全ての `Date` と `Detail`（第N回／休講／イベント）を入れた
- [ ] 4限・5限の内容を、決まっている範囲で入れた
- [ ] ファシリ担当を向こう1〜2ヶ月分入れ、依頼を出した
- [ ] `聴講可否` を各回に設定した
- [ ] バッファ回に理由を書いた
- [ ] **Slackで全体に流し、チャンネルにピン留めした**
- [ ] **英語話者が読める形になっている**（名簿の `J or E` を確認）

## 学期の最後にやること

- [ ] **継続フォームの回収**（次学期の輪読候補＋ファシリ資料が提出要件）
- [ ] 次のゼミ長への引き継ぎ（→ `hoda-zemicho-assistant`）
- [ ] 今学期のシートを、`その他` 列の学びを残した状態でアーカイブする

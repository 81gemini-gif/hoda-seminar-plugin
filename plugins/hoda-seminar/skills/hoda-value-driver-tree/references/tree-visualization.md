# ツリーと表の作り方

## 計算テーブル（Excel／Python）

10年 × ドライバーのマトリクスを作る。列が年度、行がドライバー。

```
                    FY2016  FY2017 ... FY2025   5年変化
ROIC (%)              6.2     6.8         5.1    -1.7pt
 NOPATマージン (%)     5.5     5.9         4.8    -1.1pt
  売上総利益率 (%)     32.1    32.4        30.2   -2.2pt
  販管費率 (%)         25.0    24.9        24.1   -0.8pt
   うち人件費率 (%)    11.2    11.4        12.0   +0.8pt
   うちR&D費率 (%)      4.1     4.0         3.2   -0.9pt
  実効税率 (%)         30.5    30.1        30.8   +0.3pt
 投下資本回転率 (回)    1.13    1.15        1.06   -0.09
  運転資本回転率 (回)   4.20    4.31        3.85   -0.35
   DSO (日)            62      60          71     +11
   DIO (日)            48      47          55     +7
   DPO (日)            41      42          43     +1
  固定資産回転率 (回)   1.55    1.58        1.48   -0.10
WACC (%)               5.1     5.0         5.4    +0.3pt
ROIC - WACC (pt)      +1.1    +1.8        -0.3    -1.4pt
```

**単位は必ず書く。** 保田研のスライド作法では、金額系は百万円に統一。率はpt表記、回転は「回」「日」。

## ツリー図（スライド）

- 左から右へ流れる階層構造。最左に ROIC、右に行くほど細かいドライバー。
- 各ボックスに「指標名／直近値／(5年前値)／変化幅」の3行を入れる。
- **悪化しているノードだけ**アクセント色（テンプレのaccent2 `FE802C` オレンジ）で塗る。良いところは無彩色。全部塗ると何も伝わらない。
- 掛け算・足し算の関係は「×」「＋」の記号を分岐点に置く。
- 保田研のスライド作法に従い、**枠線や横罫線は極力入れない**。階層は余白と位置で表現する。

## 折れ線グラフ

- X軸は年度（FY表記で統一）。
- **横罫線は入れない。**Y軸の目盛線は消すか、極薄のグレーにとどめる。
- 系列名は凡例ではなく**線の右端に直接ラベル**を置く方が読みやすい。
- ROIC−WACCのスプレッドは、ゼロラインを明示した棒グラフか面グラフにすると効く。プラス／マイナスで色を分ける。
- 単位・出所を必ず入れる。

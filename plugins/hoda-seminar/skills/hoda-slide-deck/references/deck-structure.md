# 提案デッキの標準構成

実際の保田研の最終発表資料（ライフネット生命、アント・キャピタル・パートナーズ）から抽出した型。企業提案・合同ゼミ発表はこの順で組む。

## 全体の並び

| # | スライド | レイアウト | 中身 |
|---|---|---|---|
| 1 | **表紙** | 表紙 | 下記参照 |
| 2 | **つかみ**（任意） | 基本スライド-線無し | 1枚で世界観を示す。企業のキャラクター画像やビジュアルを使い、一言メッセージを置く |
| 3 | **前回のリキャップ／中間発表サマリー** | 基本スライド | 最終発表のとき必須。中間で何を言ったかを1枚で |
| 4 | **本プレゼンの目的** | 基本スライド-タイトルのみ 等 | `目的：〜` `手段：〜` の2行だけ。極端に情報量を落とす |
| 5 | **Executive Summary** | 基本スライド | 下記参照。**最も重要な1枚** |
| 6 | **目次 / Table of Contents** | 基本スライド | 章番号＋章タイトル。英語表記を併記 |
| 7〜 | **中表紙 → 本編** | 中表紙 → 基本スライド | 章ごとに繰り返す |
| 末 | **Appendix** | 中表紙 → 基本スライド | 聞かれたら出す詳細データ |

## 表紙

```
（上部・小）  〇〇株式会社様 最終発表
（大）       「そこまでやるか、アントキャピタル2」
（中）       ～圧倒的投資先目線による徹底的な投資リターンの追求～
（下）       2025年11月25日
            慶應義塾大学 保田研究会
            宮武陸・大宮舞凜・山脇大河・松原尚生・中島月菜
```

- **メインタイトルはキャッチコピーにする。**分析の要約ではない。「フェアネスは届け方が9割」「そこまでやるか、アントキャピタル2」のように、覚えて帰ってもらえる一言
- **サブタイトルは `～` で挟んで、提案の実質を書く。**「〜コアバリューの再定義による持続的成長〜」
- 発表者名は `・` または `,` 区切り
- 敬称は `御中` または `様`。宛先の書き方は先方に合わせる

## Executive Summary

**リード文1〜2行＋章ごとの ✓ 箇条書き**という決まった形。

```
（リード文）本プレゼンでは、ライフネットのコアバリューを「徹底的なフェアネスの追求」と位置付け、
保険の加入や見直しを考える際に『顧客から第一想起される存在』となることで、持続的な成長を実現
するための戦略をご提案する

1. 前回のリキャップ：ライフネットの現状とあるべき姿
  ✓ 昨今のライフネットの成長は停滞しつつあり、持続的成長のためシェアの拡大が必要
  ✓ 本来的なライフネットらしさとは「徹底的なフェアネスの追求」

2. ライフネット独自の提供価値の再解釈と持続的成長に向けた全社戦略
  ✓ ...
```

- **章番号＋章タイトルを見出しにし、その下に ✓ で結論だけを並べる。**
- **各 ✓ はスタンスを取った一文。**「〜が課題」「〜がカギとなる」
- ここだけ読めば提案の全体が分かる状態にする

### エグサマの判断基準

**エグサマは目次ではない。**章タイトルを並べただけのものは失格。

| 良し悪し | 判定 |
|---|---|
| ✓ の一文が「〜について分析した」 | ×。何をやったかではなく、**何が分かったか**を書く |
| ✓ の一文が「〜が課題」「〜がカギとなる」 | ○ |
| リード文に提案の結論が入っていない | ×。リード文の1文だけで「何をどうしろと言っているのか」が伝わること |
| ✓ が章あたり3個以上ある | ×。**章あたり1〜2個**に絞る。絞れないのは論理が整理されていない証拠 |
| 本編を読まないと ✓ の意味が分からない | ×。エグサマは単独で完結させる |

### エグサマを書くタイミング

**最初と最後に2回書く。**

1. **スライドを作る前**：ストーリーラインを固めた直後に書く。ここで書けないなら、まだ提案が固まっていない。**この段階でゼミ長・先生に見せる**
2. **スライドを作り終わった後**：実際に作った本編と照合して書き直す。作っているうちに主張がズレるので必ず見直す

### 聞き手別に使い分ける

キメヘン（→ `hoda-kimehen`）で聞き手を複数書き出しているはず。**エグサマは最も重要な聞き手1人に向けて書く。**

- 提案先企業の意思決定者向け → 「御社が明日から何を変えるべきか」で書く
- 合同ゼミ・コンペ向け → 「この研究で何が新しく分かったか」で書く

両方を1枚に詰め込むと、どちらにも刺さらない。

## 本編スライドのタイトル

**`テーマ：結論` の形式が保田研の標準。**

- ○「株価成長：一時の成長曲線は直近では鈍化、再成長が課題」
- ○「【再掲】現状の業界内でのポジショニング：尖ったニッチ」
- ×「株価推移」（テーマだけで結論がない）

**タイトルで結論を言い、リード文でその裏付けを1〜2行、コンテンツで図表を出す**という3層構造。

```
タイトル：  株価成長：一時の成長曲線は直近では鈍化、再成長が課題
リード文：  競合と比較して直近5年の株価は比較的堅調に成長している様には見えるが、足元では
           成長速度が鈍化しており目標の3,000円代到達までの道のりはラクではないということが理解できる
コンテンツ： 株価推移の折れ線グラフ（自社＋競合3社、月末終値）
出所：      出所：Capital IQ より作成
```

## 使い回すときのプレフィックス

- **`【再掲】`** — 中間発表や前の章で出したスライドを再度出すとき。必ず付ける
- **`（再掲）`** — 同上（表記ゆれは1つのデッキ内で統一する）

## 注記

略称を使う場合、Executive Summary の下部に注として定義する。

```
注：本プレゼンでは以降、アント・キャピタル・パートナーズをアントキャピタル、
Buyout Investment GroupをBI、Solution Investment GroupをSIと表記
```

## 2列レイアウトの使い方

同じ指標を2つの切り口で見せるときに使う。左右にサブタイトルを置く。

```
左サブタイトル：経常収益の伸び率では競合を突き放す
右サブタイトル：経常収益の絶対額の推移では競合に劣後
```

**この使い方が保田研らしい**。「一見良く見えるが、別の見方をすると課題がある」という論理を1枚で示せる。

## 出所の実例

```
出所：ライフネット生命 ミツモロウの画像を公式HPより
出所：Capital IQ, 長谷部智也・河野博（2025）『戦略コンサルの技術』日本能率協会マネジメントセンターより作成
出典：「苦しかったときの話をしようか」森岡毅著、ノースサンド Entrance Book
```

- 書籍を引用するときは、著者名・刊行年・書名・出版社まで書く
- 複数ソースを組み合わせたなら全部並べて「より作成」で締める

## Appendix

- 本編に入れると Busy になる詳細データを全部ここに逃がす
- 質疑で聞かれたときに出す前提なので、**1枚1論点で作る**
- 目次にも `Appendix` として載せる

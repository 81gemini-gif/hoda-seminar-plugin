# スライド作法 全ルール

授業運営部のレクチャー資料と、実際の提案資料から抽出した保田研の全ルール。**破ると必ず指摘される。**

## 大原則

**「伝える」ではなく「伝わる」ものにする。**読み手・聞き手を意識する。

## ワンスライドワンメッセージ

- **1枚のスライドで言うことは1つだけ。**
- そのメッセージはリード文に置き、**スタンスを取る。**裏付けとなるファクトや論理はコンテンツ部分に置く
- タイトルは **`テーマ：結論`** 形式（例：「株価成長：一時の成長曲線は直近では鈍化、再成長が課題」）
- 言いたいことが2つあるなら、スライドを2枚に分ける

## 文章

| ルール | 詳細 |
|---|---|
| **文末の「。」は使用しない** | 全スライドで統一。**引用の中でのみ「。」を使ってよい** |
| **ですます調にしない** | 常体で書く |
| スタンスを取る | 「〜という側面がある」「〜が重要と考えられる」で逃げない |
| 体言止めと言い切りは1枚の中で揃える | 混在させない |

## 箇条書き

- **第1階層は「✓」**
- **第2階層は「・」**
- 「●」「■」「-」「1.」は使わない
- **3階層以上は作らない。**作りたくなったらスライドを分ける
- 1枚あたり6行までを目安にする

## グラフ

| ルール | 詳細 |
|---|---|
| **目盛線（横線）を消す** | グリッド線を入れない。表の縦線・横線も消す |
| **単位を必ず明記する** | **財務系データは百万円で統一** |
| **強調したいものを強調する** | 自社＝濃紺、注目させたい系列＝オレンジ、その他＝薄グレー。全部カラフルにしない |
| **Apple to apple** | **各セグメントは違うグラフになっても、同じ色になるように統一する。**セグメントAが左のグラフで青、右のグラフで赤、は禁止 |
| 何のグラフか分かるタイトルを付ける | 「売上高」ではなく「主要5社の売上高推移（FY2016-FY2025）」 |
| 軸ラベルは「タイトル（単位）」形式 | 例：`株価（円）` `経常収益（兆円）` |
| 系列名は線の右端に直接置く | 凡例ボックスより読みやすい |

## 表

- **縦線と横線は見づらくなるため消す。**罫線に頼らず、余白と揃えで構造を出す
- 何の表か分かるタイトルを付ける

## 配色（テーマカラー）

| 用途 | HEX |
|---|---|
| 自社・主役 | `#243E4D`（濃紺） |
| 強調・注目 | `#FE802C`（オレンジ） |
| 補助 | `#FCC949` `#A1C182` `#589C87` `#31BCB7` |
| 脇役・競合 | `#E8E8E8`（薄グレー） |
| 文字 | `#3A3A3A` |

**対企業の提案では、随所にその企業のロゴカラーを仕込む。**主役の系列、強調ボックス、章扉のアクセントに使う。

## 出所

- **必ず書く**
- 表記は **`出所：〜`**（「出典」ではなく「出所」で統一）
- **スライドマスターの左下のテキストボックス**に書き込む。本文中に置かない
- 加工している場合は「〜より作成」「〜よりチーム作成」を付ける
- 書籍を引用するときは著者名・刊行年・書名・出版社まで書く
- 2列レイアウトでは左右それぞれの出所欄を埋める

```
出所：〇〇株式会社「有価証券報告書」（FY2025）よりチーム作成
出所：Capital IQ, 長谷部智也・河野博（2025）『戦略コンサルの技術』日本能率協会マネジメントセンターより作成
```

## 再掲

**同じスライドを再度使用する際は `【再掲】` と記載する。**表記は1つのデッキ内で統一する。

## フォント

- 日本語：**ＭＳ Ｐゴシック**（テンプレのテーマで設定済み）
- 欧文：Segoe UI（テーマ設定済み）
- **テンプレのテーマフォントをそのまま使う。**個別にフォントを上書きしない

## 禁止事項

- **ハイパーリンクは使用しない。**URLを見せる必要があるならテキストとして書く
- **極力Busyなスライドにしない。**要素が多いと感じたら分割する
- **「ご清聴ありがとうございました」スライドは作らない。**最後のスライドには「これだけは覚えて帰ってほしい」を詰め込む

## 印刷・転送を前提にする（保田先生からの指摘）

**対企業のプレゼンでは、画面で見られるとは限らない。**ここを外すと、内容が良くても伝わらない。

### 1. 白黒・2in1で印刷される前提で作る

> 企業では印刷して読む人が多い（偉い人ほど）。その場合、**2ページを1枚にして白黒印刷することがほとんど**。2ページを1枚に印刷すると、皆さんが思っているよりも半分のサイズになるので、読めない（文字が判別しない）ページが結構出てくる。

- **文字サイズは、半分にしても読める大きさにする**
- **グラフは白黒印刷だと何が何を指しているか分からなくなる。**色分けだけに頼らず、**グラフ内に直接ラベルを振る**
  - 系列名を線の右端に置く（保田研の作図作法はもともとこれ）
  - 濃淡・線種（実線／破線／点線）・マーカー形状でも区別できるようにする
  - 凡例ボックスだけで区別させない

### 2. 転送されて単独で読まれる前提で作る

> 企業内で、当日参加できない人にもプレゼンファイルは転送されていく。**資料を見ただけで理解できるようにしたくなる。ただ、そうするとワーディになる。**

ワーディにならずに理解しやすくするには：

- **文字を大きくする**
- **太字を活用する**
- **丸で囲む**

**シンプルなんだけどメリハリのあるスライドにする。**説明を足すのではなく、強弱で理解させる。

### 3. 最後に必ず印刷して読み返す

> **一番確実なのは、作成したプレゼンファイルを印刷して読み返すこと。**

対企業のプレゼン前は、**白黒・2in1で実際に印刷して読み返す。**画面上のチェックだけで済ませない。

### 印刷チェックリスト（対企業プレゼン前）

- [ ] 白黒・2in1で印刷して読み返した
- [ ] 半分のサイズでも全ての文字が判別できる
- [ ] グラフの各系列に**直接ラベル**が振ってある
- [ ] グラフが白黒でも系列を区別できる（濃淡・線種・マーカー）
- [ ] 単独で読んでも主旨が伝わる（ただしワーディになっていない）
- [ ] 強調が文字サイズ・太字・囲みで表現されている

## 提案の中身に関するルール

- **新規事業やM&Aを提案する際は、株価や財務にどれほど影響があるのか、具体的な年数と実現方法まで言及する。**定性的な提案で終わらせない
- **質疑応答用に「見せたいスライド」を別途作成する。**本編には入れず、聞かれたら出す（Appendix）

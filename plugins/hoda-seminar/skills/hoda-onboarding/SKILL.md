# 新規ゼミ生オンボーディング

**保田研は学期単位で人が入れ替わる。**「前からいる人は知っている」を前提にした説明をしない。出戻りのメンバーにも、変わった点を伝える。

## 使い方

新規生から質問が来たら、下の順に必要なところだけ答える。**全部を一度に浴びせない。**

学期頭のレクチャー資料を作る依頼なら、この構成をそのまま使う（実際に授業運営部が使っている構成）：

1. これまでの保田研究会の活動と今学期の見通し
2. アウトプットに関して意識してほしいこと
3. リサーチに関して意識してほしいこと
4. チームでPJに取り組む際意識してほしいこと

---

## 1. まず知っておくこと

### 活動は三本柱

| 柱 | 中身 |
|---|---|
| **輪読**（4限） | 論文やケーススタディを読み、議論する。**保田先生がいるコマ** |
| **プロジェクト**（5限） | 4〜6人のチームで取り組む |
| **ゼミ運営** | ゼミがより楽しく、より学びあるものになるように活動する。部署制（授業運営部・イベント運営部・広報部・会計） |

### プロジェクトの種類

- **企業との共同プロジェクト**：企業価値向上のための戦略提案（過去：パナソニックHD、ヤマハ、チェンジHD、ライフネット生命、アント・キャピタル・パートナーズ、サツドラ）
- **学術的コンペへの参加**：日経ストックリーグ、資産形成学生論文アワード、CFA Institute Research Challenge、プロネクサス懸賞論文
- **実証論文**：非財務資本が企業の財務パフォーマンスに与える影響 など

### 輪読の種類

- **ケーススタディ**：ハーバードケースや書籍を通じ、株主価値と社会的価値の在り方について考える
- **実証論文**：定量研究の読み方を学びながら、最先端の知見をベースに議論する

**事前課題は必ずやってから来る。**やっていない状態での参加は、他の40名の時間を奪う。詳細と過去の課題例は `hoda-weekly-ops` にある。

## 2. アウトプットについて

**大原則：読み手・聞き手を意識すること。「伝える」ではなく「伝わる」ものに。**

### スライドを作る前に

**キメヘン**（キ＝聞き手／メ＝メインメッセージ／ヘン＝起こしたい変化）を埋める。→ `hoda-kimehen`

### スライドのルール

保田研には守るべき明確なルールがある。**知らずに作ると必ず作り直しになる。**→ `hoda-slide-deck`（特に references/style-rules.md）

最低限これだけは：

- **ワンスライドワンメッセージ**
- **文末に「。」を付けない／ですます調にしない**
- **箇条書きは ✓、その下は ・**
- **グラフの目盛線・表の罫線は消す。単位は百万円で統一**
- **Apple to apple：同じセグメントは全グラフで同じ色に**
- **出所を必ず左下に `出所：〜` で書く**
- **【再掲】を付ける**
- **ご清聴スライドは作らない**

### 発表するとき

→ `hoda-presentation-readiness` の「当日」の節を読む。

## 3. リサーチについて

**妥協したリサーチから良いアウトプットは生まれない。**

**パブリックに落ちている情報を最大限有効活用する。実は思っている何倍も拾ってこれる情報量は多い。**

- どこから何を取るか、SPEEDA・Capital IQへのアクセス方法（VPN、KOSMOS）、各開示書類の読み方 → `hoda-research`
- 実証分析用のデータセットの作り方 → `hoda-dataset-howto`
- 初めて実証分析をやるなら → `hoda-empirical-roadmap`

**生成AIについて**：情報の選択は人の手で、情報活用はAIに。**必ず情報元を参照すること。**

## 4. チームで取り組むときに

→ `hoda-context` スキルの references/code-of-conduct.md を読む。**ここが保田研のコア。**

要点だけ：

- **ATI（圧倒的当事者意識）とラストマンシップ**（最後まで責任を持つ覚悟）
- **Slackの連絡は24時間以内に何らかのリアクションを。**スタンプ1つでいい
- **リマインドされたらおしまい**
- **Taker ではなく Super Giver に**
- **「何かできることありますか？」は相手のタスクを増やす。**自分でタスクを探す
- **価値のない意見はない。**「周りが優秀だから」「自分は後輩だから」は関係ない
- **Yes and / Good・More。**批評と批判は違う
- **テキストはポジティブが半減、ネガティブが10倍で伝わる**

## 5. 最初の1ヶ月でやること

- [ ] Slackに入り、必要なチャンネルに参加する
- [ ] Driveの共有フォルダにアクセスできるか確認する
- [ ] **名簿に自分の情報が入っているか確認する**（`J or E`、学年と在籍学期数、部署）
- [ ] 部署の配属を受ける（初回のゼミで調整する）
- [ ] **VPN接続とSPEEDA/Capital IQへのアクセスを一度試しておく。**発表直前に詰まると詰む
- [ ] スライドテンプレートを手元に置く
- [ ] PJチームの顔合わせで、自分が使えるツール（R / Python / Excel）と週に出せる時間を正直に言う
- [ ] 最初の輪読の事前課題をやる

---

## 6. 出戻り・留学から戻ってきた人へ

- 名簿の `留学` / `休学` セクションから本体に戻してもらう
- **その間に変わったこと**を確認する：部署構成、ゼミ長、週次の進め方、PJの体制、スライドテンプレの版
- 前学期の引き継ぎ資料（Driveにある）を読む
- **在籍歴が長い人ほど、新規生から見て「聞ける人」になる。**知っていることは積極的に言語化して渡す

## 7. よくある質問

| 質問 | 答え |
|---|---|
| ゼミ以外にどれくらい時間を使うか | 研究のフェーズやゼミ運営の内容によるが、基本的に週2〜5時間程度 |
| 経営学の知識やインターン・投資経験がないと厳しいか | 学ぶことが好きな人であれば問題ない |
| 入ゼミ選考は学生がやるのか | 保田先生のみが行う |
| 4年生から入っても卒プロ（GP）の指導を受けられるか | GP指導は3年生までに2学期以上在籍した学生を優先するため、受けられない可能性が高い。個別事情がある場合は先に先生に相談する |
| 出戻り・2度目の応募はできるか | 歓迎されている |

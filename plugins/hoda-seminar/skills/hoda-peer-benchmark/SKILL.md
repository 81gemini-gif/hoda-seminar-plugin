# ピア比較・長期時系列ベンチマーク

保田研の分析で最も効く一枚は、たいてい**10〜20年の折れ線で自社と競合を並べたグラフ**。単年のスナップショットや表だけでは議論が動かない。

## 1. ピアグループを組む

ここを雑にやると全部が崩れる。**ユーザーに必ず確認を取る。**

### 選定基準（この順で絞る）

1. **事業内容の類似**：セグメント構成が近いか。売上の過半が同じ市場か。
2. **規模**：売上または時価総額で概ね1/3〜3倍のレンジ。
3. **地域**：国内比較か、グローバルピアを入れるか。グローバルを入れるなら会計基準（日本基準／IFRS／US GAAP）の差を注記する。
4. **上場・非上場**：非上場は株価系の比較から外れる。財務のみの比較になる旨を明示する。

### 実務

- EDINET DBの `screen_companies`（業種・規模で絞る）と `find_peer_strategies`（同業の戦略から探す）で候補を出す。
- **5〜8社**が扱いやすい上限。それ以上は折れ線が読めなくなる。
- 「会社が自社で挙げている競合」（有報の事業等のリスク、統合報告書）と、「市場が見ている競合」（アナリストレポート、指数構成）がズレることがある。**ズレていたらそれ自体が論点。**
- 選んだ理由と外した理由を1枚に書く。ピアグループの妥当性は必ず突っ込まれる。

## 2. 比較する3層

### 層1：ファンダメンタルズ（10年）

`get_financials` を各社について取得。以下を折れ線で並べる。

- 売上高成長率（CAGRも併記）
- 営業利益率
- ROE / ROIC
- 営業CFマージン
- 自己資本比率、ネットD/E
- 総還元性向（配当＋自社株買い ÷ 純利益）

### 層2：株価パフォーマンス（10〜20年）

- **リベース必須。** 起点を100として指数化する。生の株価を重ねても意味がない。
- ベンチマークを必ず入れる：TOPIX、東証33業種の該当業種指数。グローバルピアがいるならMSCI ACWI等も。
- 配当込みか除くかを明示する。企業価値の議論では**TSR（配当込み総株主利回り）**で見るのが筋。
- 起点の取り方で絵が変わるので、**複数の起点（10年前、5年前、コロナ前、社長交代時など）で見て、恣意的でない起点を選ぶ。**選んだ理由を書く。

### 層3：バリュエーション・マルチプル（10年）

- PER、PBR、EV/EBITDA、EV/売上、配当利回り
- **各社の推移＋ピア中央値**を並べる。自社が中央値からどれだけ乖離しているか（ディスカウント／プレミアム）が論点。
- PBRとROEの散布図（横軸ROE、縦軸PBR）は東証のPBR改善要請の文脈で定番。回帰線を引き、自社が線の上か下かを見る。

## 3. 作図の作法（保田研標準）

`references/chart-conventions.md` に詳細。要点：

- **自社＝濃紺 `#243E4D`（太線）／強調したい競合＝オレンジ `#FE802C`／その他競合＝薄グレー `#E8E8E8`（細線）／ベンチマーク＝破線**
- **横罫線は入れない。**
- 系列名は凡例ではなく線の右端に直接置く。
- 金額の単位は**百万円で統一**。
- X軸はFY表記（FY2016 …）。決算期がずれる会社が混ざるときは注記する。
- グラフには必ず「何の表／グラフか」が分かるタイトルを付ける。
- 出所は左下に「出所：〜」。

## 4. 読み解きの型

グラフを並べて終わりにしない。**必ず次の3問に答える。**

1. **いつから差がついたか。** 変曲点を特定し、そこで何が起きたか（経営交代、M&A、事業撤退、規制変更）を有報・適時開示で裏取りする（`get_events`, `get_company_history`）。
2. **差はドライバーのどこで生まれているか。** → `hoda-value-driver-tree` に接続。マージンか回転か、それとも資本構成か。
3. **市場はその差をどう織り込んでいるか。** ファンダの差以上にマルチプルの差が大きいなら、市場は将来の悪化を織り込んでいる。小さいなら見落としがあるかもしれない。これが投資提案・企業提案のフックになる。

## やってはいけないこと

- ピアグループの選定理由を書かない。
- 起点を都合よく選んで「当社は市場をアウトパフォーム」と言う。
- 会計基準の違うピアを注記なしで並べる。
- 競合を全部違う色で塗る。何を見せたいのか分からなくなる。

# リサーチの掟

## 大原則

**パブリックに落ちている情報を最大限有効活用する。**

**実は思っている何倍もパブリックから拾ってこれる情報量は多い。**「情報がない」と言う前に、下のソースを全部当たったかを確認する。

**妥協したリサーチから良いアウトプットは生まれない。**

---

## 1. 情報ソース一覧

### 財務情報

| ソース | 中身 |
|---|---|
| **決算短信** | 四半期・年度の速報。証券取引所ルールに従うため、記載項目と順番はほぼ同じ。連結業績、セグメント、BS、PL、CF |
| **有価証券報告書** | 金商法に基づく公式開示。**企業価値や将来性、リスクを判断するための最も重要で信頼性の高い情報源** |
| **決算説明会資料** | 実績の増減要因、来期以降の見通し、戦略、株主還元が丁寧に説明されている |

### 非財務情報

| ソース | 中身 |
|---|---|
| **統合報告書** | 財務と非財務を統合し、長期的な価値創造ストーリーを伝える。**企業の独自性が強く、記載項目や順番に違いがある。すべての企業が発行しているわけではない** |
| **中期経営計画** | 今後3〜5年の経営目標と戦略 |
| **サステナビリティレポート** | ESG領域の詳細 |
| **新聞記事** | 日経新聞 |
| **学術論文** | **査読付き論文**を優先する |
| **公官庁の開示資料** | 政策提言、ホワイトペーパー |
| **書籍** | その企業の創業者・幹部が書いているもの、第三者が取材を基に書いているもの |
| **民間コンサルファーム等の発行資料** | 一部有効なものもあるが**取り扱い注意**。ポジショントークが混ざる |

各書類の中身の詳細は `references/disclosure-guide.md` を読む。

### 書籍の活用（保田研が特に推奨）

**その企業の創業者や役員自身が執筆している書籍、あるいは第三者が取材・寄稿を依頼し出版している書籍がある場合、積極的に活用する。**

- 創業者本人が執筆する書籍：経営思想、判断の背景が読める（例：稲盛和夫『生き方』）
- 第三者が取材・寄稿を依頼し出版している書籍：業界構造や外部からの評価が読める（例：日本バイアウト研究所『続・事業再編とバイアウト』）

**開示資料には出てこない「なぜそう決めたか」がここにある。**企業提案の説得力が一段変わる。

## 2. データベース（大学契約）

### アクセスの前提

**キャンパスの学内wifiに繋げる、もしくはVPN接続が必要。**

VPN接続の方法：

1. 「慶應 sfc VPN」で検索
2. **「SSL-VPN(WebVPN)」を選択**
3. 指示に従い、使いたいWebページのURLにアクセス（KOSMOS、データベースナビ）

データベースへのアクセス：

1. **KOSMOS** 上部のバーから「データベース」を選択
2. 「SPEEDA」や「Capital IQ」を検索

### SPEEDA

**できること**：業界分析、財務分析、過去のM&Aの記録、他社比較

**注意点（重要）**：

- **追い出し機能ありの同時接続数1。**他の人が使っていると入れない／自分が追い出される
- **使い終わったらすぐログアウトする。**繋ぎっぱなしにしない
- **早朝は空いているのでおすすめ**

### その他

| DB | 得意なもの |
|---|---|
| **Capital IQ** | グローバル財務、コンプス、取引事例 |
| **Bloomberg / Refinitiv** | 株価、マルチプル、コンセンサス予想、ESGスコア |
| **日経NEEDS / 日経バリューサーチ** | 日本企業の財務データ、記事、業界情報 |
| **Astramanager** | 財務データ・スクリーニング |

### EDINET DBコネクタ（MCP）

このプラグインから直接呼べる。**まずここを試すと速い。**有報ベースの財務時系列、セグメント、販管費内訳、株主構成、政策保有株、役員報酬、有報テキスト、統合報告書、中計KPIのコミット vs 実績まで取れる。

→ 使い方は `hoda-company-scan`

## 3. 生成AIの使い方

**保田研の方針：情報の選択は人の手で、情報活用はAIに。**

### やってはいけないこと

- **情報収集において過度に依存する。**AIが出した事実をそのまま使わない
- **必ず情報元を参照する。**AIが挙げた出所を自分で開いて確認する
- AIが書いた文章をそのままアウトプットに載せる。**「AIの文章だと頭に残らない」**というのは360°FBでも実際に指摘されている

### やるべきこと

**適切なプロンプトを与えれば作業を最適化してくれる。**人間がやれば数時間以上かかるビジュアライズも、丁寧に最適化された指示出しさえ徹底すればものの数分で終わる。

**「AIの性能は問題ではなく、指示の質が問題」**

### 良いプロンプトの実例（保田研で実際に使われたもの）

```
ストラテジー・マップ（散布図での軌跡）「推移」を時間軸ではなく、
「利益率 vs 効率性」のポジション移動で表現します。
縦軸：営業利益率／横軸：総資産回転率
各社の20年間の動きを「線（トレース）」で繋ぎます。
これでROEデュポン分解した場合のNECと競合2社の推移を一目で比較できるような
ビジュアライズを行いたい。データはこっちから渡すから、最終的に縦横比3:8の画像として
出力して。背景は白で文字は黒、フォントはMS Pゴシックで、なるべく見やすいサイズとレイアウトで。
グラフに横線はいらないから消して。軸ラベルは大きめに見やすく、「タイトル（単位）」で表示すること。
グラフ全体的にモノクロの濃淡で3社をビジュアライズして。NECのトレースだけは赤で表記して。
営業利益率⇒EBITDAマージンで代用して（その旨記載せず営業利益率として記載してOK）。
総資産回転率はそのまま使って。バブルサイズの財務レバレッジだけど、総資産/自己資本の指標は
このデータセットには無いんだけど、総債務/自己資本（D/Eレシオ）はあるから、
これから逆算してレバレッジ算出して。
```

**この例から学ぶべきこと**：

1. **何を見せたいのか（分析の意図）を先に書く**
2. **軸・系列・データの対応を明示する**
3. **出力形式（アスペクト比、背景色、フォント、色指定）まで指定する**
4. **保田研のスライド作法（横線なし、軸ラベルは「タイトル（単位）」、MS Pゴシック）をプロンプトに入れる**
5. **データが足りないときの代替（EBITDAマージンで代用、D/Eレシオから逆算）を自分で指示する**

## 4. リサーチのチェックリスト

企業について調べるとき、以下を全部当たったかを確認する。

- [ ] 直近3期の**有価証券報告書**（事業等のリスク、MD&A、従業員の状況まで）
- [ ] 直近の**決算短信**と**決算説明会資料**
- [ ] **統合報告書**（発行していれば）
- [ ] **中期経営計画**と、**前中計のKPI達成率**
- [ ] **サステナビリティレポート**
- [ ] コーポレート・ガバナンス報告書
- [ ] 適時開示（TDnet）の直近1年分
- [ ] 日経の記事検索（社名で直近1年）
- [ ] **その企業・業界に関する書籍**があるか
- [ ] 関連する**査読付き論文**
- [ ] 官公庁の業界統計・政策資料
- [ ] 競合他社の同じ資料（比較のため）

**発表直前まで直近の開示を追う。**発表当日に「先週出た開示を知らない」は致命傷。

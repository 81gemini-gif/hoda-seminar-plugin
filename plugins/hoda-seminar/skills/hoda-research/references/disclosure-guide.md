# 開示書類の読み方

## 有価証券報告書

毎年提出する、金融商品取引法に基づく公式開示書類。財務情報に加え、事業内容・リスク・経営戦略・ガバナンスまで網羅。**企業価値や将来性、リスクを判断するための最も重要で信頼性の高い情報源。**

| 章 | 中身 | 保田研で使うところ |
|---|---|---|
| **企業情報** | 経営指標等の推移、沿革、事業内容 | 5年分の主要指標が一覧で取れる。沿革は変曲点の特定に使う |
| **事業の状況** | 経営方針、**事業等のリスク**、研究開発活動 | リスクの記載は、会社が何を怖がっているかの一次情報。競合の認識もここに出る |
| **設備の状況** | 設備投資等の概要 | 固定資産回転率の悪化要因を調べるとき |
| **会社の状況** | 株式、議決権、**コーポレートガバナンス** | 株主構成、取締役会構成、役員報酬、政策保有株式 |
| **連結財務諸表** | BS、PL、CF、株主資本等変動計算書 | 全ての財務分析の起点 |

**従業員の状況**（従業員数、平均年齢、平均勤続年数、平均年間給与、女性管理職比率など）は人的資本経営の議論で必ず使う。

## 統合報告書

企業の財務情報と非財務情報を統合し、**長期的な価値創造のストーリー**をステークホルダーに伝える報告書。

- **企業の独自性が強く、記載されている項目や順番に違いがある**
- **すべての企業が発行しているわけではない**

| 中身 | |
|---|---|
| 財務情報 | 売上高、営業利益、当期純利益 |
| 会社情報・株式情報 | 歴史・沿革、主要大株主、株式分布状況 |
| 非財務情報 | トップメッセージ／サステナビリティ課題と取り組み（**マテリアリティ**）／ミッション・ビジョン・バリュー・パーパス／セグメント別戦略／社外取締役座談会／ESGの取り組み |

**注意**：統合報告書は会社が自分を語る文書。「弊社の強み」は仮説であって事実ではない。**中計KPIの達成実績で裏を取る**（EDINET DBの `get_kg_kpi_track_record`）。

保田研では**統合報告書そのものを提案対象にした実績**もある（ヤマハへの「より学生にとって分かりやすく魅力的な統合報告書」提案）。また、毎年秋学期の年末年始に**日経統合報告書アワードの採点をお手伝い**しているので、読み込みの型はゼミ内に蓄積がある。

## 決算短信

企業が四半期・年度の決算情報を投資家向けに速報としてまとめた財務資料。**証券取引所のルールに従って開示されるため、記載項目と順番はほぼ同じ。**→ 複数社の比較がしやすい。

| 中身 |
|---|
| 連結業績（売上高、営業利益、親会社所有者帰属四半期利益） |
| 事業別セグメントの状況 |
| 所在地別の状況 |
| 貸借対照表 |
| 損益計算書 |
| キャッシュフロー計算書 |

## 決算説明会資料

四半期・年度の決算説明会に際して作成・開示される資料。**実績の増減要因や来期以降の見通し、戦略・株主還元について丁寧に説明されている。**

| 中身 |
|---|
| 決算サマリー（累計実績、通期見通し） |
| 実績（売上・利益の実績、客数や単価への分解、増減要因の詳細） |
| 見通し（事業環境を踏まえた来期以降） |
| 戦略（推進すること、投資すること） |
| 配当（自社株買い、株主優待、株式分割） |

**短信では分からない「なぜそうなったか」がここにある。**KPIを客数×単価に分解した資料は、ドライバー分析の起点として使える。

## 中期経営計画

企業の今後3〜5年間の経営計画。中期的な経営目標と、それを達成するための具体的な戦略。

| 中身 |
|---|
| **前中期経営計画の振り返り／KPIの達成率** |
| 3〜5年後の外部環境変化 |
| 財務目標・非財務目標 |
| ESGに関する取組み |
| 製品領域の拡大／研究開発 |
| 人的投資／組織・風土づくり |
| 事業ポートフォリオ |
| キャッシュアロケーション |

**最初に見るのは「前中計の振り返りとKPI達成率」。**ここが未達続きなら、新中計の数字も割り引いて読む必要がある。保田研の提案・バリュエーションでは、この達成率で会社計画をディスカウントするのが作法。

## その他

| 書類 | 使いどころ |
|---|---|
| **コーポレート・ガバナンス報告書** | 取締役会の構成、独立性、指名・報酬委員会、政策保有の方針 |
| **大量保有報告書** | 5%超の大株主の異動。アクティビストの参入検知 |
| **適時開示（TDnet）** | M&A、業績修正、不祥事、自社株買い。イベントスタディの起点 |
| **有価証券届出書・臨時報告書** | 資金調達、大規模な組織再編 |

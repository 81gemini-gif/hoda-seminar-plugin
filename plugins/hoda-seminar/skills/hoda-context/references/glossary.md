# 保田研 用語集

新規ゼミ生・出戻りゼミ生が最初に詰まるところ。会話に出てきたら必ずここで意味を確認してから進める。

## 活動の三本柱

| 用語 | 意味 |
|---|---|
| **輪読（りんどく）** | 4限の中心活動。Harvard Business Schoolのケーススタディ、査読付き実証論文、直近の事例（アクティビストのホワイトペーパー等）を題材に、担当班が事前課題を設計しファシリテーションする。実際の経営陣・投資家の目線で議論するのが保田研流。 |
| **PJワーク（プロジェクトワーク）** | 5限の中心活動。4〜6名の班で、企業提案・学術コンペ・実証分析のいずれかに取り組む。 |
| **ゼミ運営** | 第三の柱。ゼミがより楽しく学びあるものになるよう学生自身が動かす領域。授業運営部などの部署がある。 |

## プロジェクトの型

| 用語 | 意味 |
|---|---|
| **企業PJ** | 実在の企業に対し「企業価値向上と社会的価値向上の両立」をテーマに提案する。過去の相手先：パナソニックHD、ヤマハ、チェンジHD、ライフネット生命、アルプスアルパイン等。班の呼称は取り組み内容で付く（アクティビスト班、ポートフォリオ班、経営戦略班など）。 |
| **実証分析** | 定量データを用いた仮説検証型の研究。例：「監督と執行の分離は企業価値を高めるか」「株主構成は配当変更に影響するか」「企業不祥事が株価に与える影響」「株式分割の価格帯設計と市場反応」。 |
| **懸賞論文／学術コンペ** | 日経ストックリーグ（日経＋野村アセット主催、保田研から入賞実績あり）、資産形成学生論文アワード、プロネクサス懸賞論文、CFA Institute Research Challenge。 |
| **中間発表／最終発表** | 学期のマイルストーン。学期前にゼミ長が先生と相談して日程を確定させる。 |
| **360°FB回** | 月1回、PJの進捗報告会とあわせて実施する相互フィードバックの回。 |

## フレームワーク

| 用語 | 意味 |
|---|---|
| **キメヘン** | 保田研の提案設計フレームワーク。**キ**（聞き手は誰か）・**メ**（メインメッセージは何か）・**ヘン**（起こしたい変化は何か）の3列を、聞き手ごとに複数行で埋める。詳細は `hoda-kimehen` スキル。 |
| **クロスSWOT** | SWOTの4象限を掛け合わせ（強み×機会＝積極攻勢 等）、打ち手に落とす分析。保田研の企業提案では定番。 |

## 運営まわり

| 用語 | 意味 |
|---|---|
| **ゼミ長** | 2024年春に本格的にポスト化。毎学期交代が原則。男女1名ずつ＋α で、現在は3名体制が定着。 |
| **授業運営部** | ゼミ運営の部署のひとつ。ゼミ長と協力して輪読コンテンツの選定などを担う。 |
| **継続フォーム** | 各ゼミ生が学期末に提出する次学期履修希望フォーム。提出要件として「輪読で扱うべきコンテンツ＋その輪読ファシリ資料」の提案が含まれる。**次学期の輪読はここから選ぶ**ので、運営の起点になる重要な仕組み。 |
| **合ゼミ（合同ゼミ）** | 他大学のファイナンス系ゼミとの合同研究発表会。大阪大学、一橋大学、大阪公立大学、早稲田大学など。 |
| **日経統合報告書アワード** | 毎年秋学期の年末年始に、保田研として採点をお手伝いしている。 |
| **ゼミ合宿** | 春学期は4月、秋学期は8〜9月に実施。新規生は参加必須の扱いになることがある。 |
| **工場見学** | 提携企業の工場・開発センターへの訪問（アルプスアルパイン宮城、トヨタ紡織猿投、イトーキ滋賀など）。 |
| **追いコン／OBOG会** | 春学期末（7月）に追いコン、8月にOBOG会。 |
| **GP（卒業プロジェクト）** | SFCの卒業研究。保田先生の指導は3年生までに2学期以上在籍した学生を優先。 |

## 略語

| 略語 | 正式 |
|---|---|
| ROIC | 投下資本利益率 / Return on Invested Capital |
| ROE | 自己資本利益率 / Return on Equity |
| WACC | 加重平均資本コスト / Weighted Average Cost of Capital |
| EV | 企業価値 / Enterprise Value |
| DCF | 割引キャッシュフロー法 / Discounted Cash Flow |
| TSR | 株主総利回り / Total Shareholder Return |
| PBR / PER | 株価純資産倍率 / 株価収益率 |
| 有報 | 有価証券報告書 |
| 短信 | 決算短信 |

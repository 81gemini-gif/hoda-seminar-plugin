# 保田研の掟

## コア：ATI と ラストマンシップ

**保田研の行動規範の根っこはここにある。**他のルールは全部この2語の系譜。

| 概念 | 意味 |
|---|---|
| **ATI（圧倒的当事者意識）** | 自分ごととして引き受ける。傍観者にならない |
| **ラストマンシップ** | 最後まで責任を持つ覚悟。自分が最後の砦だと思って動く |

ゼミ長から全体に共有されたメッセージ（要旨）：

> 「自分がやらなくても誰かが勝手に幹事をやってくれていて、自分は参加する側である」とか、自分からみんなにとって必要なタスクを拾ってくれている人に対して「何か手伝えることはありますか？」と聞いてしまうとか、こういったことは一昔前の保田研にはほとんど無かった。
>
> ゼミは皆で学び、**全体としての学びを最大化する**ことに意義がある。それを理解して行動できないならば、究極ゼミに所属している必要が無い。
>
> **40名規模になった保田研で、全員の利害の最大公約数を探すことは不可能に近い。つまり、一人一人が保田研メンバーとしてのATI・ラストマンシップをもって、少しでも多くの自己犠牲を進んで引き受けるということをしない限り、この組織は回らない。**
>
> 「私は保田研のためになることを出来たよ」と自信をもって言える人が一人でも増えるとよい。

**この規模のゼミが回っているのは、誰かが自己犠牲を引き受けているから。**そのことを前提に振る舞う。

## 組織の「気」

保田先生から全体に共有されたメッセージ（要旨）：

> 欠席者が多い日は、いろんなことが偶然重なった結果発生するのですが、これまでの私の経験では、それらは偶然ではなくて、**組織全体として抱える「気」が悪いとそうなります**。気には、運気、元気、やる気、気力、気遣い、気配り、雰囲気など、たくさんの様々な気があります。
>
> **気は、良くすることができます。**
>
> **些細なことに感謝できる人間になりましょう。**
>
> **テキストメッセージは、ポジティブな内容は半減で受け取られ、ネガティブなものは10倍で受け取られますので、テキストの扱い方は注意しつつ。**

### ここから導かれる実務ルール

- **Slackやドキュメントで指摘を書くときは、意図した強さの10倍で伝わると思って書く。**厳しいことを言う必要があるときほど、対面か通話にする
- **褒めるときは、意図した強さの2倍書く。**十分だと思う量では足りない
- **感謝を明示的に書く。**幹事、ファシリ、資料をまとめた人、Zoomを立てた人に対して
- 出席率が落ちている、反応が薄い、という状態を「たまたま」で流さない。**組織の状態のシグナルとして扱う**

## 研究会全体で心がけること

### Slackの連絡は24時間以内に何らかのリアクションをする

**スタンプ1つ押すだけでいい。**反応がないと、送った側は「読まれたのか、動いているのか」が分からず止まる。

#### なぜ反応の速さがそこまで重要か

保田研で共有されている考え方：

> **反応の速さは"打順"を上げる。**
>
> 面白い仕事や紹介のチャンスは、反応の早いやつから順番に降ってくる。
>
> **幸運は元々はランダムだが、人が媒介するので結果的には偏在する。**
>
> Slackの投稿に真っ先にスタンプを押し、セミナーでは最前列に座ってリアクションをし、何か誘われたら即「行きます」と連絡し、ノリで参加しなさい。その先で"たまたま"あなたの求めていたチャンスに巡り会うから。

つまり、24時間以内のリアクションは**マナーの問題ではなく、自分の機会の問題**。企業訪問、講演、幹事、コンペ、インターンの紹介は、声をかける側が「反応が返ってくる人」を思い浮かべて配る。

- 投稿には**真っ先にスタンプを押す**
- 講演・セミナーでは**最前列に座ってリアクションする**
- 誘われたら**即「行きます」**。予定を確認してからではなく、まず返す
- **ノリで参加する。** "Action trumps everything."


### 時間には余裕を持つ

- **「締切日ギリで良いか」マインドは×**
- **リマインドされたらおしまい。**リマインドが必要な状態になった時点で、既に相手の時間を奪っている

### ファシリや幹事へリスペクトを持って取り組む

自分たちがスムーズに物事をやれている背景には、そのために準備をしてくれた人がいる。それを忘れない。

### Taker ではなく Super Giver になる

- いつも受け身では×
- **率先して、幹事や手伝いをする**

## PJにおいて心がけること

### 自分の意見を大切に

- **価値のない意見はない＝すべての意見に価値がある**
- **「周りが優秀だから」「自分は後輩だから」は関係ない。**あなたの意見を共有すること

### 相手を尊重する

- 一人の視野・視点だけで突き進むのは×
- 意見を言うときは**言い方に気をつける**
- **Yes and**（否定せず、乗せる）
- **Good / More**（良かった点と、もっと良くなる点で伝える。360°FBもこの形式）
- **批評と批判は違う。**「ここがダメ」ではなく「こうすればもっと良くなる」を探す
- 外の時間でも積極的にPJメンバー・研究会メンバーに会う

### 自分で自分のタスクを探す

- **「何かできることありますか？」は相手のタスクを増やす**
- 自分ができることを探して、積極的に取り組む

## Key Takeaway（レクチャーの締め）

1. **アウトプットは読み手／聞き手を意識すること。「伝える」ではなく「伝わる」ものに**
2. **そのために保田研全体で共有された「アウトプットの水準」を理解することが重要**
3. **リサーチは徹底的に行うこと。妥協したリサーチから良いアウトプットは生まれない**
4. **確立されたリサーチツール／ソースを有効活用すること**
5. **研究会活動ではとにかく主体的に、互いを尊重し、保田研全体のためになることは何かを考え、とにかく楽しく取り組むこと**

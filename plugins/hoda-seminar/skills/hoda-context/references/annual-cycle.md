# 保田研 年間サイクル

学期設計・イベント逆算の土台。日付は年によってずれるので、**必ず今年の実際の日程をゼミ長・先生に確認してから確定させる**。ここに書いてあるのは「例年こうなる」という相場観。

## 春学期（4月〜7月）

| 時期 | イベント | 動き出しの目安 |
|---|---|---|
| 3月中 | 学期前準備：輪読コンテンツ選定、PJ体制決定 | 前学期末の継続フォーム提出直後から |
| 4月 | 春学期ゼミ合宿 | 2月中に幹事を立てる |
| 4月 第1週 | 初回ゼミ。向こう1〜2ヶ月分の輪読スケジュールが決まっている状態にする | — |
| 5月 | PJ中間発表 | 学期頭に日程確定 |
| 7月 | PJ最終発表 / 追いコン | 追いコン幹事は6月に |
| 7月中旬 | 秋学期の選考希望フォーム締切（例：7/19） | 説明会資料は6月末に完成させる |
| 8月 | OBOG会 | 6月に幹事を立てる |
| 8〜9月 | 秋学期ゼミ合宿、工場見学 | 6〜7月に幹事を立てる |
| 9月 | 秋学期の履修選抜 | — |

## 秋学期（9月〜1月）

| 時期 | イベント | 動き出しの目安 |
|---|---|---|
| 9月末 | 学期開始。輪読スケジュールとPJ体制が決まっている状態にする | 8月中に先生と詰める |
| 10月末 | **合ゼミで発表する班を全体議論に上げるリマインドを打つ**（毎回ギリギリまで決まらないので、ゼミ長が能動的に議題化する） | — |
| 11月末〜12月頭 | 大阪大学との合同ゼミ | **7〜8月に幹事を立て、Slackに幹事チャンネルを作成。**先方大学とのやり取りをこまめに回す。ゼミ長は監視し、必要なら巻き取るか他に移管する |
| 12月中旬 | 早稲田大学との合同ゼミ（阪大合ゼミよりワークロードは軽い） | 9月に幹事が決まっていればよい。対応内容は阪大合ゼミと同じ |
| 12月 | PJ中間発表 | 学期頭に日程確定 |
| 12月下旬〜1月 | **日経統合報告書アワードの採点お手伝い** | 12月頭には担当割りを終える |
| 1月中旬 | 日経ストックリーグ 応募締切 | 参加班は10月には走り出す |
| 1月 | PJ最終発表 | — |
| 1月末 | 継続フォーム提出（次学期の輪読候補＋ファシリ資料が提出要件） | — |

## 逆算の原則

- **合ゼミ級のイベント（対外・他大学が絡む）は開催の3〜4ヶ月前に幹事を立てる。** 相手方との調整リードタイムが読めないため。
- **学内で完結するイベント（合宿、追いコン、OBOG会）は2ヶ月前。**
- **応募型コンペは締切の3ヶ月前**に班を確定させないと分析が間に合わない。
- 発表班の決定は放っておくと必ず遅れる。**開催の1ヶ月前を締切としてゼミ長が議題に上げる。**

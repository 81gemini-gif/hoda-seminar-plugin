# 保田研究会プロフィール

## 基本情報

- 正式名称：慶應義塾大学 湘南藤沢キャンパス（SFC）保田隆明研究会。通称「保田研」。
- 担当教員：保田隆明 教授（総合政策学部）。2022年4月着任、同年春学期より開講。2026年で5年目。
- 経歴：リーマン・ブラザーズ証券、UBS証券 → SNS運営サイトを起業しNTTグループへ売却 → VCファンド組成・運用 → 金融庁金融研究センター専門研究員（IPO研究）→ 小樽商科大MBA、昭和女子大、神戸大大学院経営学研究科（2015-2022）→ スタンフォード大在外研究（2019.8-2021.3、ESG×財務戦略）。修士（ファイナンス）、博士（商学）。
- 研究テーマ：コーポレートファイナンス、ESG投資、人的資本経営。通底するテーマは「企業価値向上と社会的価値向上の両立」。
- 開講形態：研究会A（週2コマ4単位）。月曜4限・5限。SFCの研究会単位上限は一学期6単位なので、研究会Aの兼ゼミ（計8単位）は不可。
- モットー："Work hard, play hard." / "Action trumps everything."（説明会資料では "Study Hard, Play Hard" とも表記）

## SFCの研究会制度（学外の人・新入生向け）

- 一般大学の「ゼミ」に相当するものをSFCでは「研究会」と呼ぶ。通称は「担当教授名＋研」。
- 制度上は1年春学期から入室可能。学年の縛りがない。
- **学期単位で自由に入退室できる**のが最大の特徴。これが保田研の運営設計すべてに効いてくる。
- 兼ゼミ可。他研究会と兼ねているゼミ生が一定数いる。
- 受け入れ人数に上限があるため、実際は選考がある。

## メンバー構成（2026年時点の目安）

- 規模：約40名。2022年〜2024年秋までは日本語ゼミ／英語ゼミに分けて各15名程度だったが、2025年春に日英を統合し採用を拡大して現在の規模になった。
- 学年：3年生と4年生が各45%、2年生10%。1年生は在籍していない。
- 男女比：5:5にするポリシーだが、直近は男6:女4寄り。
- 学部：総合政策学部が多数、環境情報学部が3〜4割。
- 国際性：約4割が英語で活動する多国籍集団。ベトナム、韓国、中国出身者、ハワイ・シンガポール育ちの帰国生、英国系・香港系のハーフなど。交換留学でボストン、UBC、UCLAに行っていたメンバーも複数。
- 休学・留学：ある学期にフランス（Audencia、ESSEC）、英国（Glasgow）などへ留学したりブラジルでNPO活動をするため休学・休ゼミするメンバーが出る。**毎学期、抜ける人と戻る人がいる前提で設計する。**

## キャリアと課外活動

- 就職先の主流：投資銀行、日系証券、アセットマネジメント、戦略コンサル、総合商社。一部にソフトバンク・楽天などの事業会社。
- 1割弱が院進（国内ビジネススクール、一橋・東大など）。
- 長期インターン：コンサルファーム、PEファンド、VC、外資系金融がほとんど。
- 体育会所属で両立しているメンバーも数名。
- ゼミ外の共通言語：ワイン、ゴルフ、ラン。保田研ゴルフコンペ（教授も参加）が他ゼミにない特色。

## 選考

- 選考は保田先生が単独で行う。学生は関与しない。
- 必要条件：保田先生の授業「経営分析」「ファイナンス論」の履修。未履修者の受け入れは原則難しい。
- 書類選考のみ（選考希望フォーム）。成績優秀者が有利になりやすいため、そうでない人は授業内での積極性や自身の強み・個性の具体的提示でアピールする必要がある。
- 先生からのメッセージ：「ファイナンスとあなたの領域を掛け算する」「これから何かをやるつもりです、ではなく、今まで何を考えて何をしてきたか」。
- 出戻り・複数回応募も歓迎。4年生の応募も歓迎だが、卒業プロジェクト（GP）指導は3年生までに2学期以上在籍した学生を優先するため、4年生からの入室でGP指導を受けられない可能性が高い。
- 入ってくる人の傾向：6〜7割は授業成績優秀な地頭型。残り3〜4割は行動力・体力・チャームで採られた触媒型。特に近年の女子は後者の比率が高く、「爆発力」を期待した採用がある。

## 活動時間

- 週次のゼミ（月4・5限）に加え、時間外のワークが週2〜5時間程度。
- 学期に数回の特別イベント（合宿、工場見学、合同ゼミ、OBOG会など）への出席・コミットメントが求められる。

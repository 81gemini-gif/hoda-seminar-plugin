# 保田研究会コンテキスト

保田研の活動に関わるあらゆる作業の前提となる共通知識。他の `hoda-*` スキルは必要に応じてこのスキルの `references/` を読む。

## 使い方

1. ユーザーの依頼が保田研の活動（輪読・PJワーク・スライド・ゼミ運営）に関わるか判断する。
2. 関わるなら、下の「参照ファイル」から必要なものだけ読む。全部読まない。
3. 用語の意味が曖昧なまま進めない。`references/glossary.md` で確認する。

## 参照ファイル

| ファイル | いつ読むか |
|---|---|
| `references/seminar-profile.md` | ゼミの成り立ち・メンバー構成・カルチャーを踏まえた判断が要るとき |
| `references/glossary.md` | 保田研固有の用語が出てきたとき（必ず確認する） |
| `references/annual-cycle.md` | 学期設計・イベント逆算・スケジュールの話が出たとき |

| `references/code-of-conduct.md` | チームでの振る舞い、連絡、意見の出し方が関わるとき。**新規生への説明では必ず読む** |
| `references/org-structure.md` | 部署・ゼミ長・名簿・PJチーム編成が関わるとき |

## 常に効かせる原則

- **モットーは "Work hard, play hard." と "Action trumps everything."** 議論を精緻にするより、まず動いて叩き台を出す方が保田研の作法に合う。完璧な計画より、粗くても具体的な第一稿を出す。
- **社会人と対峙して恥ずかしくない水準**が全成果物の基準。学生の練習作品としての言い訳をしない。
- **企業価値向上と社会的価値向上の両立**が研究会の一貫したテーマ。片方だけの提案は保田研の色が出ていないと判断する。
- **英語話者が約4割在籍する。** 成果物やアナウンスを作るときは、英語版が必要かを必ず確認する。専門用語には初出時に英語を併記する（例：ROIC（投下資本利益率 / Return on Invested Capital））。
- **人の入れ替わりが激しい。** SFCの研究会は学期単位で入退室が自由で、休学・留学・出戻りが常態。「前からいる人は知っている」を前提にした説明をしない。暗黙知は必ず言語化して残す。

## 英語話者向けの注記 / For English-speaking members

All `hoda-*` skills are written in Japanese because the seminar's working documents are in Japanese. If you prefer English, just say so — the skill logic is language-independent, and Claude will produce English deliverables while still following the same seminar standards.

# クロスSWOT

## 位置づけ

保田研の企業提案の流れの中では、**分析と提案の接続点**。

```
hoda-company-scan（事実の把握）
  → hoda-value-driver-tree（どこで価値が漏れているか）
  → hoda-peer-benchmark（競合と比べてどうか）
  → hoda-cross-swot（何をすべきか）      ← ここ
  → hoda-kimehen（誰に何を言って何を変えるか）
  → hoda-slide-deck（提案資料）
```

**SWOTを単なる4象限の箱埋めで終わらせない。**保田研でSWOTを出す価値は、掛け合わせて施策を導くところにしかない。

## 1. 4象限を埋める

### 内部要因

| 象限 | 定義 | エビデンスの取り方 |
|---|---|---|
| **S（強み）** | 競合が真似しにくい、自社が持つ経営資源・能力 | 財務指標でピアを上回っている項目（`hoda-peer-benchmark`）、特許・シェア、人材、ブランド、顧客基盤 |
| **W（弱み）** | 競合に劣後している、または価値を毀損している要素 | ROICツリーの悪化ノード、ピアより低いマージン・回転率、ガバナンス上の課題 |

### 外部要因

| 象限 | 定義 | エビデンスの取り方 |
|---|---|---|
| **O（機会）** | 自社の外で起きている、追い風になりうる変化 | 市場規模の成長、規制緩和、技術変化、人口動態、東証の資本効率要請 |
| **P/T（脅威）** | 自社の外で起きている、逆風になりうる変化 | 新規参入、代替技術、規制強化、原材料高、地政学 |

### 品質基準

- **各象限3〜5個。** それ以上は絞れていない証拠。
- **必ず数字か一次情報を添える。** 「技術力が高い」は強みではない。「R&D費率が業界中央値の1.8倍で、直近5年の新製品売上比率が32%（業界平均18%）」なら強み。
- **強みと機会を混同しない。** 強みは自社の中にあるもの。「市場が伸びている」は機会であって強みではない。
- 外部要因はPEST（政治・経済・社会・技術）やファイブフォースで漏れをチェックする。

## 2. 掛け合わせる（ここが本体）

|  | **O（機会）** | **T（脅威）** |
|---|---|---|
| **S（強み）** | **積極攻勢**：強みを活かして機会を最大限に取る | **差別化**：強みで脅威を回避・無効化する |
| **W（弱み）** | **段階的改善**：弱みを克服して機会を逃さない | **専守防衛／撤退**：最悪シナリオを避ける。事業撤退・縮小の判断もここ |

### 埋め方

1. 各セルで、S×Oなら**具体的な強み1つと具体的な機会1つ**を名指しでペアにする。
2. そのペアから導かれる**施策を1文で書く。**動詞で終える。「〜を活かして〜に参入する」
3. 各施策に **①インパクト（企業価値への効き）②実現可能性 ③時間軸** の3軸で評価を付ける。
4. **積極攻勢セルから2つ、それ以外から1つ**程度に絞る。全セルを平等に扱わない。提案は優先順位そのもの。

## 3. 企業価値への接続（保田研の必須ステップ）

**ここをやらないと保田研の提案にならない。** 導いた施策を、必ず財務ドライバーに接続する。

| 施策 | 効くドライバー | 定量インパクトの試算 |
|---|---|---|
| （例）高付加価値品へのミックス転換 | 売上総利益率 | +2.0pt → NOPATマージン +1.4pt → ROIC +1.5pt |
| （例）不採算拠点の統廃合 | 固定資産回転率 | 1.48 → 1.62回 → ROIC +0.6pt |
| （例）政策保有株の縮減と自社株買い | 投下資本／自己資本 | 投下資本 -8% → ROIC +0.4pt、ROE +1.1pt |

試算は粗くてよい。**桁が合っていること**と、**前提が書いてあること**が重要。

## 4. 社会的価値の軸を必ず入れる

保田研のテーマは企業価値向上と社会的価値向上の両立。**財務的に正しいだけの施策は評価されない。**

各施策について、以下を1行ずつ書く。

- この施策で**誰が得をするか**（株主・従業員・取引先・顧客・地域社会）
- この施策で**誰が損をするか**、その緩和策は何か
- 中長期の**無形資産（人的資本、ブランド、信頼）**への影響

「人員削減でコスト削減」のような施策を出す場合は、**必ず**人的資本への影響と代替案を併記する。単純なコストカット提案は保田研の色が出ていない。

## 5. アウトプット

- クロスSWOTの2×2マトリクス（スライド1枚）。各セルに施策を1〜2個。文字を詰め込みすぎない
- 施策の優先順位マトリクス（インパクト×実現可能性の散布図）
- 選んだ施策の詳細（1施策1枚）：現状の数字 → 打ち手 → 想定インパクト → 社会的価値への影響 → 実行上のリスク

スライド化は `hoda-slide-deck` に渡す。

# バリュエーション

## 大原則

- **単一手法で結論を出さない。** 必ず2つ以上の手法をぶつけ、レンジで示す。
- **前提を全部見せる。** バリュエーションは前提の集合体。前提が見えない算定は保田研では評価されない。
- **感応度分析を必ず付ける。** 点推定だけの提出は不可。

## 1. 前提を固める

先に決める。ここが曖昧なまま計算に入らない。

- **評価の目的**：投資判断（買い／売り）／買収価額の妥当性／経営陣への提案の裏付け／PBR1倍割れの解消余地
- **基準日**：株価・為替・金利をいつ時点で取るか
- **単位と通貨**：百万円で統一
- **連結か単体か**：原則連結

## 2. DCF法

### FCFの定義（保田研の標準）

```
FCFF = NOPAT + 減価償却費 - 設備投資 - 運転資本増加額
     = 営業利益 × (1 - 実効税率) + D&A - CapEx - ΔWC
```

FCFF（企業へのFCF）をWACCで割り引いて企業価値（EV）を出し、そこからネット有利子負債を引いて株式価値を出す。FCFE（株主へのFCF）を株主資本コストで割る方法もあるが、**保田研では原則FCFF法**。混ぜない。

### 予測期間

- **5年**が標準。事業サイクルが長い（インフラ、製薬、資源）なら10年。
- 予測は必ず**ドライバーベース**で組む。「売上成長率5%」ではなく、数量×単価、あるいはセグメント別に積み上げる。
- 会社の中計がある場合、中計を起点にしつつ**中計KPIの過去の達成率（`get_kg_kpi_track_record`）で割り引く。**中計をそのまま使うのは楽観すぎる。

### WACC

```
WACC = E/(D+E) × Re + D/(D+E) × Rd × (1 - t)
Re (CAPM) = リスクフリーレート + β × マーケットリスクプレミアム
```

| 項目 | 保田研の取り方 |
|---|---|
| リスクフリーレート | 日本10年国債利回り（基準日時点）。財務省サイトの実績値を使う |
| マーケットリスクプレミアム | 5〜6%を基本レンジ。使った値と根拠（Damodaran等）を明記 |
| β | 対象企業の過去5年週次 vs TOPIX の回帰。**アンレバードβに戻してピア中央値を取り、対象の資本構成でリレバーする**のが望ましい（ハマダ式） |
| 負債コスト Rd | 支払利息 ÷ 平均有利子負債、または格付ベースのスプレッド＋RF |
| 資本構成 E/D | 時価ベース。簿価を使わない |
| 実効税率 t | 法定実効税率（約30〜31%）か、過去5年の実績平均 |

**日本企業は現金保有が厚いことが多い。**ネット有利子負債がマイナス（ネットキャッシュ）になるケースの扱いを明示する。

### 継続価値（TV）

2通り出して比較する。

```
永久成長法：TV = FCF(n+1) ÷ (WACC - g)      g は 0〜1%（日本の名目成長率を超えない）
出口倍率法：TV = EBITDA(n) × 出口EV/EBITDA倍率   倍率はピアの現在の中央値を基準に
```

**TVがEVの70%を超えたら警告を出す。**その場合、予測期間の議論はほぼ意味を持っておらず、実質的にTVの前提だけで結論が決まっている。予測期間を延ばすか、出口倍率法に寄せる。

### 感応度分析

WACC × 永久成長率（または出口倍率）の2軸マトリクスを必ず作る。中心値の上下に0.5ptずつ、5×5。

## 3. マルチプル法

- ピアグループは `hoda-peer-benchmark` の基準で組む。
- 使う倍率：EV/EBITDA、EV/EBIT、PER、PBR。業種特性で選ぶ（金融ならPBR・PER中心、設備産業ならEV/EBITDA）。
- **ピア中央値を使う。**平均は外れ値に引っ張られる。
- ヒストリカルレンジ（過去5〜10年の自社倍率の推移）も併記する。「今が歴史的に見て高いのか安いのか」が論点になる。
- 類似取引（M&A）倍率が取れるなら別枠で。支配権プレミアムが乗っている点を注記する。

## 4. SOTP（Sum of the Parts）

複数セグメントを持つ企業では必須級。`get_segments` でセグメント別の売上・利益・資産を取り、セグメントごとに別の倍率を当てて足し上げる。

- コングロマリット・ディスカウントの定量化ができる。**「事業ポートフォリオを組み替えれば〇〇億円の価値が顕在化する」**という保田研の提案の定番ロジックがここから出る。
- 本社費用の配賦とネット負債の扱いを明示する。

## 5. アウトプット

### フットボールチャート

各手法のレンジを横棒で並べ、現在株価を縦線で示す。保田研の提案スライドの定番。

```
DCF（WACC 5.5-6.5%, g 0.5-1.0%）   ├──────────┤
EV/EBITDA（ピア中央値 ±1σ）          ├───────┤
PER（ピア中央値 ±1σ）                    ├──────┤
SOTP                                ├────────────┤
                        現在株価 ─────┃
```

### 必ず書くこと

- 前提一覧（WACC構成要素、成長率、予測期間、基準日）
- 感応度マトリクス
- **結論のスタンス**：「割安と考える」「現在の株価は妥当」と言い切る。「〜という見方もある」で逃げない
- 反証（何が起きたらこの結論が崩れるか）

## 6. 保田研テーマへの接続

バリュエーションを出して終わりにしない。

- **ROIC−WACCのスプレッド**（→ `hoda-value-driver-tree`）と接続する。スプレッドがマイナスなら、成長投資が価値を毀損している。
- **社会的価値の観点**：ESG要因が資本コストに与える影響（低いβ、低い負債コスト）を定性的にでも論じる。人的資本への投資はP/L上は費用だが、DCFでは将来FCFの押し上げ要因になりうる。この非対称性が保田研の議論のネタ。
- **東証のPBR1倍割れ要請**の文脈では、「ROE > 株主資本コスト」が成立しているかを必ずチェックする。

## 使えるツールとデータ

- 財務データ：EDINET DBコネクタ（`get_financials`, `get_segments`, `get_earnings`）
- 追加で使える既存プラグイン：`financial-analysis:dcf-model`（Excel DCFモデルの構築）、`financial-analysis:comps-analysis`（コンプス表の構築）、`model-builder:3-statement-model`。保田研の作法（単位・配色・出所表記）は本スキルを優先する
- 株価・β：Bloomberg / Refinitiv / Capital IQ / 日経バリューサーチ（大学契約分）

# 実証分析ロードマップ（初学者向け）

保田研で使う統計ツールは **R** が標準。以下、Rを前提に書く。Python（pandas + statsmodels/linearmodels）でも同じことができる。

## 大前提

**実証分析は「データをこねたら何か出た」ではない。「こう考えたからこう検証した」の順。**この順番を守れば、初学者でも通る分析になる。

**先に手を動かす。**"Action trumps everything." 手法を完璧に理解してから始めようとすると学期が終わる。粗い分析を回して、詰まったところを学ぶ方が速い。

---

## Step 0：これは実証分析でやるべき問いか

先に確認する。以下に当てはまらないなら、ケーススタディや企業提案の方が向いている。

- [ ] **数えられるもの**で答えが出る問いか
- [ ] **十分な数のサンプル**（企業なら最低100社、できれば数百〜数千社×年）が取れるか
- [ ] 過去に**誰かが似た問いを検証している**か（先行研究があると型を真似できる。全くないなら、それは難しすぎる可能性が高い）

---

## Step 1：リサーチクエスチョン（RQ）を立てる

### 型

> **X が Y に影響を与えるか**

保田研で実際に扱われたRQの例：

- 「監督と執行の分離」（X）は企業価値（Y）を高めるか
- 株主の構成（X）は配当の変更（Y）に影響するか
- 企業の不祥事（X）は株価（Y）にどう影響するか。不祥事の種類によって違うか
- 株式分割の価格帯設計（X）は市場反応（Y）にどう効くか

### よいRQの条件

- [ ] **XとYが両方とも数値で測れる**
- [ ] **世の中で言われているが、検証されていない**（→ そこに価値がある）
- [ ] **答えが「Yes/No」または「どちらの方向に効くか」で出る**
- [ ] 保田研のテーマ（コーポレートファイナンス、ESG、人的資本、ガバナンス）に接続している

### やりがちな失敗

| 失敗 | どう直すか |
|---|---|
| 「ESGは重要か」— 漠然としすぎ | 「ESGスコアの上昇は、翌期の資本コストを下げるか」 |
| 「日本企業はどうあるべきか」— 規範的な問いで検証できない | 「取締役会の社外比率が高い企業は、ROICが高いか」 |
| Yが測れない（「企業文化の良さ」） | 代理変数を使う。「エンゲージメントスコア」「離職率」 |

---

## Step 2：先行研究を読む

**3〜5本読めば十分。**最初から10本読もうとしない。

- 探す場所：Google Scholar、CiNii、SSRN、J-STAGE。慶應の図書館経由でジャーナルにアクセスできる
- 読む順番：**まずアブストラクトとテーブル（表）だけ**。本文は後
- **見るべきは「彼らが何をYにして、何をXにして、何をコントロールしたか」の3点。**これが自分の分析の設計図になる
- 保田研の輪読で扱った論文があれば、それが最も参考になる

読んだら1本1行でメモを残す：

```
著者(年) | Y=？ | X=？ | データ=？ | 結果=？ | 自分の研究との違い=？
```

---

## Step 3：仮説を立てる

RQを**方向付きの予想**に変える。

> H1：取締役会の社外取締役比率が高い企業ほど、ROICが高い

- **方向を書く**（高い／低い、正／負）。「関係がある」だけでは仮説にならない
- **なぜそうなるかの理屈を1〜2文で書く。**理屈のない仮説は、たまたま出た結果と区別がつかない
- 仮説は2〜4個。それ以上は絞れていない

---

## Step 4：データを集める

→ 詳細は `hoda-dataset-howto` を見る。

必要なもの：

| 種類 | 中身 |
|---|---|
| **被説明変数 Y** | 説明されたいもの（ROIC、株価リターン、配当変更フラグ） |
| **説明変数 X** | 効果を見たいもの（社外取締役比率、株主構成、不祥事発生フラグ） |
| **コントロール変数** | Yに影響しそうな他の要因。**入れないと結果が信用されない**。定番：企業規模（総資産の対数）、レバレッジ、業種ダミー、年ダミー |

**データセットの形**：1行＝1企業×1年（パネルデータ）が基本。

```
company_id  year  roic  outside_ratio  log_assets  leverage  industry  ...
1301        2020  0.062 0.33           13.2        0.41      水産
1301        2021  0.068 0.33           13.3        0.40      水産
...
```

## Step 5：データを見る（分析の前に必ずやる）

**いきなり回帰しない。**ここを飛ばすと必ず後で泣く。

```r
library(tidyverse)
df <- read_csv("data.csv")

glimpse(df)           # 変数の型と中身
summary(df)           # 最小・最大・平均・中央値・欠損数
df %>% count(year)    # 年ごとのサンプル数
```

チェックすること：

- [ ] **欠損（NA）はどれくらいあるか。**多い変数は使えない
- [ ] **外れ値はないか。**ROICが500%の企業は入力ミスか特殊要因。**上下1%をウィンザライズ（winsorize）する**のが慣行
- [ ] **変数の分布**。ヒストグラムを描く。極端に歪んでいたら対数を取る
- [ ] **XとYの散布図**を描く。ここで関係が全く見えないなら、回帰しても出ない

```r
ggplot(df, aes(x = outside_ratio, y = roic)) +
  geom_point(alpha = 0.2) + geom_smooth(method = "lm")
```

## Step 6：回帰分析を回す

### 一番シンプルな形

```r
model1 <- lm(roic ~ outside_ratio, data = df)
summary(model1)
```

### コントロール変数を足す

```r
model2 <- lm(roic ~ outside_ratio + log_assets + leverage + factor(industry) + factor(year),
             data = df)
summary(model2)
```

### パネルデータなら固定効果

同じ企業を複数年追っているなら、**企業固定効果**を入れるのが標準。「その企業がもともと持っている、変わらない特徴」の影響を取り除く。

```r
library(fixest)
model3 <- feols(roic ~ outside_ratio + log_assets + leverage | company_id + year,
                data = df, cluster = ~company_id)
summary(model3)
```

`| company_id + year` が固定効果、`cluster = ~company_id` が標準誤差のクラスタリング（同じ企業のデータは似ているので、それを考慮する）。**この2つを入れるかどうかで結果の信用度が変わる。**

### 結果の読み方（超かみ砕き）

```
                Estimate  Std. Error  t value  Pr(>|t|)
outside_ratio    0.0412      0.0158     2.61    0.0091 **
```

| 項目 | 意味 |
|---|---|
| **Estimate（係数）** | Xが1単位増えるとYがどれだけ変わるか。ここでは社外比率が1（＝100%pt）上がるとROICが4.12%pt上がる。**符号（＋／−）が仮説と合っているかを最初に見る** |
| **Std. Error** | 係数の推定のブレ幅。小さいほど精度が高い |
| **t value** | 係数 ÷ 標準誤差。**絶対値が約2を超えると「偶然ではなさそう」** |
| **Pr(>|t|)（p値）** | 「本当は効果がゼロなのに、たまたまこの結果が出る確率」。**0.05未満なら「統計的に有意」**と言う |
| `***` `**` `*` | p < 0.01 / 0.05 / 0.1 |

### 統計的有意と経済的意味は別物

**ここを間違えるゼミ生が非常に多い。**

- p値が小さい＝「効果がゼロではなさそう」というだけ
- **その効果が大きいかどうかは係数の大きさで判断する**
- ROICが0.001%pt上がるという結果は、有意でも実務的には無意味

必ず「**Xが1標準偏差動くとYがどれだけ動くか**」で語る。

## Step 7：頑健性をチェックする（robustness check）

「別の切り方でも同じ結果が出るか」を確認する。**ここまでやって初めて発表できる。**

- [ ] コントロール変数を足したり抜いたりしても符号と有意性が変わらないか
- [ ] サンプルを分けても（大企業／中小、業種別、時期別）同じ傾向か
- [ ] 外れ値を除いても結果が変わらないか
- [ ] Yの測り方を変えても（ROIC→ROE→ROA）同じか

**結果が簡単に消えるなら、それは発見ではない。**

---

## Step 8：因果を主張してよいか考える

**回帰で出た関係は「相関」であって「因果」ではない。**

3つの疑いを自分でつぶす：

| 疑い | 意味 | 対処 |
|---|---|---|
| **逆の因果** | YがXを引き起こしている可能性。「業績が良いから社外取締役を増やせた」 | Xを1期前の値にする（ラグ） |
| **見落とし変数** | XとYの両方に効く第3の要因 | コントロール変数を足す、固定効果を入れる |
| **選択バイアス** | サンプルの選び方が偏っている | 母集団の定義を明示する |

因果を強く主張したいなら、DID（差の差分析）、イベントスタディ、操作変数法などが必要。**学部の実証分析では、正直に「相関を示した」と書くのが誠実。**保田研では、無理な因果主張より正直な限界の記述が評価される。

## Step 9：アウトプットにする

### 回帰結果の表

```r
library(modelsummary)
modelsummary(list(model1, model2, model3),
             stars = TRUE, output = "regression_table.docx")
```

表に必ず載せるもの：係数、標準誤差（カッコ内）、有意水準の星、サンプル数、決定係数、固定効果の有無。

### 発表で言うこと

1. **RQと仮説**（何を問い、どう予想したか）
2. **データ**（何社×何年、出所、期間）
3. **結果**（符号、有意性、効果の大きさ）
4. **解釈**（実務的に何を意味するか）
5. **限界**（因果は言えない、サンプルの偏り、測定の限界）

**有意でなかった結果も報告する。**都合の良い結果だけ拾うのは保田研の水準に反する。

## 詰まったときは

**2週間自力で粘らない。**先生かゼミ長に聞く。実証分析経験のあるゼミ生が必ずいる。

よくある詰まりどころ：

| 症状 | たいていの原因 |
|---|---|
| データが結合できない | 企業コードの形式違い（証券コードは4桁か5桁か、文字列か数値か） |
| 係数がとんでもない値 | 単位の不統一（百万円と千円が混在）、外れ値 |
| サンプル数が激減した | 欠損のある行が自動で落ちている。`summary()` で欠損数を確認する |
| 何も有意にならない | サンプル数不足、変数の測り方が粗い、そもそも効果がない（それも結果） |
